命令行验证一次

# 1. 登录拿 token（客户账号）
curl -s -X POST http://127.0.0.1:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"yatai","password":"123456"}'

# 2. 带上 token 查商品，就能看到 6 个物料和它们的库存双池
curl -s http://127.0.0.1:8080/api/client/products \
  -H "Authorization: Bearer <上一步的 token>"
客户账号访问 /api/admin/** 会被服务端拦成 403 —— 三端隔离靠拦截器实现，不靠前端藏菜单。
