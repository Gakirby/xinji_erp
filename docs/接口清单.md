# 接口清单

- 统一前缀：无（各模块自带 `/api/client` 或 `/api/admin`）
- 统一返回：`{"code":0,"msg":"ok","data":...}`，`code=0` 成功，`code=401/403/500` 失败
- 鉴权：除 `POST /api/auth/login` 外，所有接口都要带 `Authorization: Bearer <token>`
- 分页参数：`page`（从 1 开始）、`size`，返回 `{"list":[],"total":n,"page":1,"size":10}`
- 在线调试：<http://127.0.0.1:8080/swagger-ui.html>

**鉴权规则**

| 前缀 | 谁能访问 | 越权返回 |
| --- | --- | --- |
| `/api/client/**` | 客户账号（`userType=CUSTOMER`） | `403` 只能访问客户端接口 |
| `/api/admin/**` | 员工账号（`userType=EMPLOYEE`） | `403 无权限访问管理后台接口` |
| `/api/auth/**` | 所有人 | —— |

## 一、认证

### POST /api/auth/login
登录（客户与员工共用入口）。

```json
{
  "username": "admin",
  "password": "admin123",
  "userType": "EMPLOYEE"
}
```

`userType` 可选 `EMPLOYEE` / `CUSTOMER`。返回：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "expiresIn": 43200,
    "userId": 1,
    "username": "admin",
    "userType": "EMPLOYEE",
    "role": "ADMIN",
    "displayName": "李国强"
  }
}
```

客户登录额外返回 `customerId / customerName / creditLimit / creditUsed`：

```json
{
  "username": "yatai",
  "password": "123456",
  "userType": "CUSTOMER"
}
```

```json
{
  "code": 0, "msg": "ok",

    "token": "...",
    "userId": 5, "username": "yatai", "userType": "CUSTOMER",
```

## 三、客户端 · 订单

### POST /api/client/orders
提交订单，**提交即冻结库存**，同一事务内完成授信校验。

```json
{
  "deliveryType": "DELIVERY",
  "expectedDate": "11-05 08:00 — 12:00",
  "receiver": "张伟",
  "address": "吉林省长春市二道区英俊镇建龙北路18号",
  "items": [{ "skuId": 1, "qty": 30 }],
  "remark": "工地急需"
}
```

`deliveryType`：`DELIVERY` 配送 / `PICKUP` 自提。

返回 `OrderVO`：

```json
{
  "code": 0, "msg": "ok",
  "data": {
    "order": {
      "orderNo": "XJ202611010001948",
      "customerId": 1, "customerName": "长春亚泰建材有限公司",
      "orderType": "NORMAL", "status": "PENDING_AUDIT",
      "totalQty": 30.000, "totalAmount": 2580.00,
      "freight": 0.00, "discountAmount": 0.00, "payAmount": 2580.00,
      "deliveryType": "DELIVERY", "expectedDate": "11-05 08:00 — 12:00",
      "address": "...", "receiver": "张伟",
      "createdAt": "2026-11-01 18:18:24"
    },
    "items": [{
      "orderNo": "XJ202611010001948", "skuId": 1, "skuName": "石灰石 5-10mm",
      "qty": 30.000, "price": 86.00, "amount": 2580.00,
      "settleQty": 0.000, "settleAmount": 0.00
    }],
    "statusLabel": "待审核"
  }
}
```

**失败情况**

| 场景 | 返回 |
| --- | --- |
| 可售库存不足 | `{"code":500,"msg":"「石灰石 5-10mm」可售库存不足，当前可售 2314 吨，本次需要 99999 吨"}` |
| 低于起订量 | `{"code":500,"msg":"单笔起订量为 1 吨"}` |
| 超授信额度 | `{"code":500,"msg":"超出客户授信额度：额度 800000 元，已用 214600 元，本单 600000 元"}` |
| 物料已下架 | `{"code":500,"msg":"物料「XXX」已下架"}` |

### GET /api/client/orders?status=&page=1&size=10
我的订单（只能看到自己 `customer_id` 的）。

### GET /api/client/orders/{orderNo}
订单详情，含明细与 `statusLabel`。

### POST /api/client/orders/{orderNo}/cancel?reason=客户主动取消
取消订单，释放冻结库存与授信。仅 `PENDING_AUDIT` / `AUDITED` / `DISPATCHED` 可取消。

## 四、客户端 · 秒杀

### GET /api/client/seckill/activities
活动列表。

### GET /api/client/seckill/activities/{activityId}/skus
活动 SKU，**活动池与销售池分开返回**，前端可以画两条进度条。

```json
{
  "code": 0, "msg": "ok",
  "data": [{
    "id": 2, "activityId": 1, "seckillSkuNo": "ASK-10022",
    "skuId": 1, "skuName": "石灰石 5-10mm",
    "seckillPrice": 72.00, "originalPrice": 86.00,
    "activityStock": 800.000, "soldQty": 536.000, "remainQty": 264.000,
    "limitPerUser": 60.000, "status": "ON",
    "saleableQty": 2314.000
  }]
}
```

### POST /api/client/seckill/grab
抢购。Redis Lua 原子完成：一人一单校验 → 库存判断 → DECRBY → SADD 已抢用户 → XADD 发消息。

```json
{ "seckillSkuId": 2, "qty": 20 }
```

**抢到**

```json
{"code":0,"msg":"抢购成功，请尽快提交订单",
 "data":{"success":true,"tokenNo":"TK202611010001126","seckillSkuId":2,"remainStock":244}}
```

**没抢到**（HTTP 仍是 200，业务结果看 `success`）

```json
{"code":0,"msg":"每人限抢一份，你已经抢到过了",
 "data":{"success":false,"reason":"每人限抢一份，你已经抢到过了","seckillSkuId":2,"remainStock":-1}}
```

`msg` 与 `data.reason` 一致，前端直接弹 `msg` 即可。其他 `reason`：

- `活动库存尚未预热，请稍后再试`（`-2`）
- `活动库存不足，已抢完`（`-3`）
- `超过每人限购 60.000 吨`（`-4`）

### GET /api/client/seckill/tokens/{tokenNo}
轮询令牌发放状态。`status` 变化：`ISSUED`（可下单）→ `USED` / `EXPIRED` / `FAILED`。

```json
{"code":0,"msg":"ok","data":{
  "tokenNo":"TK202611010001126","userId":5,"activityId":1,"seckillSkuId":2,"skuId":1,
  "qty":20.000,"price":72.00,"status":"ISSUED",
  "expireTime":"2026-11-01 18:33:26","createdAt":"2026-11-01 18:18:26"}}
```

### GET /api/client/seckill/tokens
我的抢购记录。

### POST /api/client/seckill/tokens/{tokenNo}/order
令牌核销下单。请求体同 `CreateOrderRequest`（只需要配送信息，`items` 可省）。

```json
{"deliveryType":"DELIVERY","expectedDate":"11-05 08:00 — 12:00",
 "receiver":"张伟","address":"吉林省长春市二道区英俊镇建龙北路18号"}
```

返回 `OrderVO`，`orderType=SECKILL`，价格取令牌上的活动价。
令牌非 `ISSUED` 时返回 `{"code":500,"msg":"令牌状态为「USED」，无法下单"}`。

## 八、后台 · 过磅

### POST /api/admin/weigh/tickets
过磅出票，自动算净重、扣水、扣杂、结算量，并回填订单明细。

```json
{
  "orderNo": "XJ202611010001948",
  "skuId": 1,
  "plateNo": "吉B·9T001",
  "driverName": "赵师傅",
  "driverPhone": "13900008811",
  "grossWeight": 52.400,
  "tareWeight": 17.200,
  "waterRate": 0.011,
  "impurityDeductWeight": 0.150,
  "weighman": "王立"
}
```

`waterRate` 是小数形式：`0.011` 表示含水率 1.1%。

```json
{"code":0,"msg":"ok","data":{
  "ticketNo":"BD202611010001937","orderNo":"XJ202611010001948","skuId":1,
  "plateNo":"吉B·9T001","driverName":"赵师傅","driverPhone":"13900008811",
  "grossWeight":52.400,"tareWeight":17.200,"netWeight":35.200,
  "waterRate":0.011,"waterDeductWeight":0.387,"impurityDeductWeight":0.150,
  "settleWeight":34.663,"weighTime":"2026-11-01 18:18:25",
  "weighman":"王立","status":"ISSUED"}}
```

计算规则：

```
净重   = 毛重 - 皮重
扣水量 = 净重 × 含水率
结算量 = 净重 - 扣水量 - 扣杂量
结算金额 = 结算量 × 物料单价   → 回填到 t_order_item.settle_amount
```

### GET /api/admin/weigh/tickets?orderNo=
磅单列表。不带 `orderNo` 时返回最近 50 条。

对账批次列表。

对账明细（每张订单的结算吨数与金额）。

### GET /api/admin/dispatch/orders?status=&keyword=
派车单列表，`keyword` 匹配订单号 / 车牌 / 客户名。

### POST /api/admin/dispatch/orders
派车。校验链：订单状态必须是 `AUDITED`（或已派车）→ 不能重复派车 → 车辆未停用且保险未过期 → 计划吨数不超过核定载重。通过后落派车单并把订单推进到 `DISPATCHED`。

```json
{"orderNo":"XJ20261101004","vehicleId":4,"driverId":4,
 "planQty":30,"planTime":"2026-11-03 07:30:00","remark":"验收派车"}
```

时间字段支持 `2026-11-03 07:30:00` 与 `2026-11-03T07:30:00` 两种写法。

典型拦截：

```
订单当前状态为「待审核」，只有已审核的订单才能派车
订单 XJ20261101004 已有进行中的派车单，不能重复派车
计划装载 45 吨超过车辆核定载重 40.000 吨
车辆 吉B·8K275 保险已于 2026-11-04 到期，请先续保再派车
```

## 十六、后台 · 发票与回款

### GET /api/admin/finance/invoices?status=&customerId=
发票列表。`status`：`PENDING` / `ISSUED` / `VOID`。

### POST /api/admin/finance/invoices
申请开票。挂应收单或对账批次，二选一；同一单据不能重复开票（作废的除外）。

```json
{"receivableId":3,"invoiceType":"VAT_SPECIAL","taxRate":0.13,"remark":"验收开票"}
```

```json
{"settlementId":2,"invoiceType":"VAT_SPECIAL"}
```

税额自动算：`amount ÷ (1 + taxRate) × taxRate`。

### POST /api/admin/finance/invoices/{id}/issue
开具。状态转 `ISSUED`，并把该批次下订单从 `SETTLED` 推进到 `INVOICED`（单笔失败只记日志，不影响开票）。

### POST /api/admin/finance/invoices/{id}/void?reason=
作废发票。

### GET /api/admin/finance/invoices/stats
`issuedAmount` / `pendingCount` / `voidCount`。

### GET /api/admin/finance/payments?customerId=&receivableId=
收款流水列表。

### POST /api/admin/finance/receivables/{id}/receive-detail?amount=20000&payMethod=CHECK&remark=银行承兑汇票
带收款方式登记回款：更新应收余额 + 写一条收款流水。

`payMethod`：`TRANSFER` 转账 / `CASH` 现金 / `CHECK` 承兑 / `DRAFT` 汇票。

> 中文参数请做 URL 编码，或直接用 body 版本（`POST /api/admin/finance/receivables/{id}/receive?amount=`）。

### GET /api/admin/finance/payments/stats
`totalReceived` / `monthReceived` / `outstanding` / `partialCount` / `unpaidCount`。

## 十八、后台 · 账号与权限

### GET /api/admin/users?userType=&keyword=&page=&size=
账号分页。`userType`：`EMPLOYEE` / `CUSTOMER`。

### POST /api/admin/users
新建账号。员工要指定 `role`（`ADMIN`/`SALES`/`FINANCE`/`WEIGH`/`DISPATCH`），**客户账号必须绑定 `customerId`**。

```json
{"username":"zhaowei","password":"123456","mobile":"13904329988",
 "userType":"EMPLOYEE","role":"SALES","employeeName":"赵伟"}
```

```json
{"username":"hd_user","password":"123456","userType":"CUSTOMER","customerId":6}
```

### PUT /api/admin/users/{id}
修改账号（密码留空表示不改）。

### POST /api/admin/users/{id}/reset-password?newPassword=abc123456
重置密码，至少 6 位。

### POST /api/admin/users/{id}/status?status=0
停用 / 启用。内置 `admin` 不允许停用；停用后登录返回 `403 账号已停用，请联系管理员`。

### GET /api/admin/users/overview
`employeeCount` / `customerCount` / `disabledCount` / `employeeRoles` / `customerAccounts`。

## 附：错误码

| code | 含义 | 典型场景 |
| --- | --- | --- |
| 0 | 成功 | —— |
| 401 | 未登录 / token 失效 | 没带 `Authorization` 头 |
| 403 | 无权限 | 客户 token 访问 `/api/admin/**` |
| 404 | 资源不存在 | 订单号写错 |
| 500 | 业务异常 | 库存不足、授信超限、状态不允许流转 |
